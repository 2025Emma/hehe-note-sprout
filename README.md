# 笔记发芽 hehe-note-sprout

给任意一张笔记执行「**本地发芽 → 外部发芽 → 专家拷问**」三层循环，生成一份结构化发芽报告，帮助碎片想法长成有根有据的永久笔记。

> **核心原则：不修改原笔记，只做连接与启发。**
> 发芽不是分类信息，而是从记录中生长洞察；拷问不是结构化审查，而是帮你把想法想透。
>
> **不挑笔记格式**：Obsidian 卡片、普通 markdown 文件、直接粘贴的一段文字都可以。Obsidian / Logseq / Foam 等支持 wikilink 的工具用户获得完整体验。

| 适用人群 | 卡片笔记实践者、知识管理爱好者、想把想法想透的写作者 |

## 核心特点

- **三层循环**：本地发芽（库内关联网络）→ 外部发芽（跨领域故事串讲）→ 专家拷问（对话式拆解）。
- **本地洞察是你的独特优势**：纯联网 AI 工具能搜外部案例，但看不见你自己知识库里隐含的 pattern——本地发芽做的就是这件事。
- **故事串讲，不是分类汇总**：每个外部案例完整展开（背景→冲突→行动→结果→洞察），结尾有自己提炼的 Aha 瞬间 + 可追溯的参考链接。
- **对话式拷问，不是检查清单**：像一位严厉的教练，直接指出逻辑漏洞，追问前提和代价，最后逼你厘清真实立场。
- **发芽标记（可选）**：已发芽笔记文件名加 `🌱`，末尾追加发芽区块，全库 wikilink 自动同步——幂等设计，重跑安全。

## 快速开始（30 秒）

把 Skill 装好后，对着 AI 工具直接说：

```
给这张卡片发芽：[[20260827-我关于产品优先级的一个判断]]
```

发芽报告会自动生成在这张笔记的旁边（`{生成日期}-我关于产品优先级的一个判断-发芽报告.md`），与笔记放一起、就近查看。

没有知识库也可以——直接粘贴一段文字：

```
给这段笔记发芽：

「……（粘贴内容）……」

（没有笔记库时自动走「外部发芽 + 专家拷问」两层模式）
```

即可得到一份发芽报告：

1. 🌱 种子摘要（2-3 句话确认地基）
2. 🔗 本地笔记的洞察（你库里的关联网络，每条附原文链接）
3. 🌐 网络洞察（3-5 个跨领域故事，每个有种子引子 + Aha 瞬间 + 参考链接）
4. 🔍 拷问（对话式拆解，追问前提、代价与动机）
5. 💡 发芽建议（2-3 个可执行动作）

## 配置（可选，开箱即用）

**无需配置即可使用**。发芽报告默认生成在**原笔记所在目录**（`笔记.md` 旁会生成 `{YYYYMMDD}-主题-发芽报告.md`），与笔记放一起。

**可选：自定义跳过目录**（全库搜索/链接同步时忽略，默认已跳过 `.obsidian`、`.trash`、`.git`、`node_modules`）。有大型归档或收件箱目录时可告诉 AI，例如：

```
全库搜索和链接同步时，跳过我的 Archives/ 和 Inbox/ 目录
```

**文件名约定（可选）**：笔记带 `YYYYMMDD-` 日期前缀也能正常识别；没有前缀不影响使用。

## 怎么调用

支持以下自然语言触发（不限于此）：

| 你想做的事 | 直接说 |
|---|---|
| 发芽一张卡 | 「给这张卡片发芽」「笔记发芽」 |
| 找关联 | 「这张笔记和库里哪些笔记有关」 |
| 补视角 | 「补充视角」「帮我找跨领域案例」 |
| 压力测试 | 「压力测试这张笔记」「拷问一下这个判断」 |
| 批量发芽 | 「把没发芽的都发芽」「哪些笔记还没发芽」 |

**默认行为**：发芽报告生成在**原笔记所在目录**，**不修改原笔记正文**。没有笔记库、直接粘贴内容时，自动走「外部发芽 + 专家拷问」两层模式，报告省略本地洞察章节。
**发芽标记（改文件名加 🌱 + 全库 wikilink 同步）首次执行前，AI 必须先向你确认**；你授权一次后，后续即可默认执行。任何一次说「只出报告不改卡片」，当次就跳过标记。

## 三层循环详解

### 第一层 · 本地发芽 🔗

从你的笔记提取种子关键词（tags / 标题 / wikilink / 全文概念），多路搜索你的笔记库：已有连接反向搜索 → 标签匹配 → 标题匹配 → 全文关键词。输出 Top 5-8 张最相关的本地笔记，并写出**关联的深度解读**——不只是列链接，而是解释"这两张笔记放在一起会产生什么新洞察"。非 wikilink 环境下「已有连接」维度自动跳过，其余搜索照常；没有笔记库时整层跳过。

### 第二层 · 外部发芽 🌐

不是分类汇总搜索结果，而是**跨领域故事串讲**：3-5 个有真实人物、时间、转折的完整故事，每个故事有「🌱 种子引子」（因为笔记提到 XX，让我想到 YY）、起承转合的展开、自己提炼的「✨ Aha 瞬间」，以及可追溯的「📎 参考文档链接」。跨领域跨度越大，冲击力越强。

### 第三层 · 专家拷问 🔍

用「专家镜片」做对话式拆解。默认组合：**段永平式（本质维度）+ 快刀青衣式（落地维度）**；另有乔布斯式、Karpathy 式、罗振宇式可按笔记类型路由。每张镜片都带「核心框架 + 最适合拷问 + 主要盲区」，完整定义见 `references/expert-lens-registry.md`（自包含，不依赖外部 Skill）。

拷问覆盖逻辑谬误、前提追问、代价计算、概念澄清、边界追问、动机追问中的至少 3-4 个维度，像一段连续的对话，不用表格、不分点。

## 安全与隐私边界

- **绝不修改原笔记正文**：报告单独存放；发芽标记只会改文件名（加 🌱）和在文件**末尾追加**区块，正文观点、论述、案例保持原样。
- **发芽标记需授权**：仅适用于 Obsidian / Logseq / Foam 等支持 wikilink 的工具。改文件名 + 全库 wikilink 同步是有破坏性的操作，首次执行前 AI 必须向你说明并征得同意。
- **幂等可重跑**：改名映射、防双 🌱 正则、区块追加都做了幂等设计，重复执行不会重复标记。
- 外部搜索结果标注来源与日期，不承诺权威性；专家拷问使用「某某式判断框架」，不声称名人在场。
- 你的知识库内容不会被写入 Skill 本身——分享 Skill 不会泄露任何笔记。
